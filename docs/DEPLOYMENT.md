# Развёртывание через Docker

Docker-образы и режим разработки проверены запуском на Docker Desktop / WSL2.
Для первого запуска читайте ../НАЧНИТЕ_ЗДЕСЬ.html. Результаты — ../DOCKER_VALIDATION.md.
Локальный production: 01_start.bat; разработка: 02_develop.bat.

Для внешнего сервера нужны HTTPS reverse proxy и фактический домен в FINGUARD_ALLOWED_HOSTS.
Не публикуйте наружу режим разработки. Общий пароль не заменяет отдельные аккаунты и роли.
Сохраняйте volume и скачивайте SQLite-копию перед обновлением/переносом.
