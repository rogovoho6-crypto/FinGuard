# Проверка выпуска для жюри

Дата: **1 ноября 2026 года**. Проверено на Windows с Docker Desktop и Linux-контейнерами.

- TypeScript проверен, браузерный интерфейс собран внутри Docker.
- **89 тестов расчётного ядра и HTTP API — OK** в отдельном тестовом контейнере.
- Обычный режим собран и запущен на свежем изолированном томе; контейнер имеет статус healthy.
- Без пароля API обычного режима возвращает HTTP 401; с локальным паролем интерфейс и API доступны.
- Загружаются собранные JavaScript и CSS; в названии страницы и видимом интерфейсе используется **FinGuard** без номера версии.
- Проверен демонстрационный каскад: №2 исключить, №3 +7 дней, №5 +40 дней, горизонт 30 дней.
  Конечный остаток **282 000 → 480 000 ₽**, изменение **+198 000 ₽**,
  обязательства после горизонта **48 000 ₽**.
- Все **9 внутренних проверок** самодиагностики проходят через API и кнопку в браузере.
- В режиме разработки исправлен прокси Vite: сохраняется исходный Host, поэтому проверка
  источника POST-запросов работает без отключения защиты сервера.
- В браузере проверены обзор, раздел «О продукте», инструменты и запуск самодиагностики.
- Перед публикацией проверены отслеживаемые файлы и история Git: локальный `.env`, базы,
  резервные копии и найденные шаблоны ключей доступа в публикуемые материалы не входят.

Технический идентификатор сборки в API и метаданных оставлен для диагностики и совместимости файлов;
в пользовательском интерфейсе номер версии не отображается.

Повторить проверки:

```sh
docker compose -f compose.test.yaml build
docker compose -f compose.test.yaml run --rm tests
```

GitHub Actions выполняет сборку и эти же тесты при изменениях `main` и в Pull Request.
Тестовые журналы локальной проверки находятся в игнорируемой папке `validation/`.
Результат автоматизации на GitHub доступен во вкладке [Actions](https://github.com/rogovoho6-crypto/FinGuard/actions).
