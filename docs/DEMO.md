# FinGuard — порядок проверки для жюри

Пошаговый запуск и работа с программой описаны в **[единой инструкции для жюри](JURY.md)**.
Она же доступна без интернета в файлах **НАЧНИТЕ_ЗДЕСЬ.html** и **ИНСТРУКЦИЯ_DOCKER.txt** в корне проекта.

Рекомендуемый порядок:

1. Запустить приложение и войти с локальным паролем.
2. Заново загрузить демонстрационный набор «Повторный платёж».
3. Проверить кандидата №2, объяснение сигнала и ручное решение.
4. Добавить три действия в сценарий и сверить контрольные суммы.
5. Сохранить сценарий и загрузить его повторно.
6. Открыть предпросмотр CSV и отменить импорт.
7. Запустить самодиагностику и проверить 9 результатов OK.

Для оценки достаточно демонстрационных данных. Настройка разработки и изменение исходников не требуются.
