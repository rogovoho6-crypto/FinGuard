# Изменения

## 6.2-web.1

- Перенесён рабочий процесс FinGuard 6.2 в браузерный интерфейс React + TypeScript.
- Добавлен FastAPI-сервер с отдельным слоем сценариев приложения и сохранённым финансовым ядром.
- Веб-версия использует отдельную SQLite-базу; перенос данных desktop выполняется через проверяемую резервную копию.
- Сохранены поиск рисков, ручные решения, импорт с предпросмотром, сверка остатка, прогноз и каскадные сценарии.
- Добавлены проверка ревизии при записи, CSRF, ограничения файлов и пароль для сетевого запуска.
- Собран Windows-файл локального сервера с включёнными файлами интерфейса; Python и Node.js пользователю не нужны.
- Подготовлены Dockerfile, Compose, справочник API и документация разработчика.
- Аккаунты, роли, аудит, PostgreSQL и публикация на внешнем хостинге остаются отдельными этапами.
