# FinGuard

Проверка платёжного реестра и прогноз денежных средств малого бизнеса.
FinGuard объясняет сигналы о возможных дублях, сохраняет решения пользователя
и показывает последствия переноса или исключения нескольких платежей из прогноза.

## Запуск для жюри

**[Полная инструкция по запуску и работе](docs/JURY.md)** ·
**[Скачать ZIP](https://github.com/rogovoho6-crypto/FinGuard/archive/refs/heads/main.zip)**

1. Установите и запустите [Docker Desktop](https://docs.docker.com/desktop/).
   На Windows используйте WSL 2 и Linux-контейнеры. Дождитесь **Engine running**.
2. Скачайте ZIP и **полностью распакуйте** его. Откройте папку **FinGuard-main**, где лежит `01_start.bat`.
3. На Windows дважды нажмите **`01_start.bat`** и дождитесь окончания сборки.
   Для macOS и Linux используйте [соответствующий раздел инструкции](docs/JURY.md#запуск-на-macos-и-linux).
4. Откройте **http://localhost:8765**. Имя пользователя — **`finguard`**.
   Пароль — значение после `FINGUARD_PASSWORD=` в созданном файле **`.env`** из папки проекта.
5. В **«Проверке командой»** загрузите набор **«Повторный платёж»** и подтвердите загрузку.
   Дальше следуйте [проверке основных функций](docs/JURY.md#проверка-основных-функций).

Первому запуску нужен интернет для загрузки компонентов. После сборки приложение работает локально;
Docker Desktop должен оставаться запущенным. Аккаунт GitHub, Python, Node.js и Git для оценки не требуются.

## Что проверить в приложении

| Функция | Где открыть | Что наблюдать |
| --- | --- | --- |
| Проверка возможного дубля | «Обзор» → «Возможные дубли» → №2 | Объяснение сигнала и сравнение с №1 |
| Ручное решение | «Платежи» → карточка №2 | «Не дубль» убирает сигнал, сохраняя сумму операции |
| Несколько изменений в одном сценарии | «Симулятор» | Независимые переносы и исключения платежей |
| Сохранение результатов | «Сохранить и сравнить» | Повторная загрузка и сравнение вариантов |
| Импорт CSV | Кнопка «Импорт CSV» | Предпросмотр до подтверждения замены |
| Самодиагностика | «Проверка командой» → «Запустить проверку» | 9 результатов OK без изменения реестра |

В [инструкции](docs/JURY.md) приведены точные действия и контрольные суммы примера:
конечный остаток **282 000 → 480 000 ₽**, обязательства после горизонта **48 000 ₽**.
Пример синтетический. Приложение не выполняет банковские переводы; сигналы о риске требуют проверки человеком.

Для остановки на Windows используйте **`03_stop.bat`**, для повторного запуска — **`01_start.bat`**.
Данные сохраняются. [Если возникла проблема при запуске](docs/JURY.md#если-приложение-не-открылось).

Автоматические проверки проекта: **[GitHub Actions](https://github.com/rogovoho6-crypto/FinGuard/actions)**.
