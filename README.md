# FinGuard Docker

Репозиторий команды: https://github.com/rogovoho6-crypto/FinGuard (Private).
Порядок работы с ветками, Pull Request и объединением: [CONTRIBUTING.md](CONTRIBUTING.md).

Начните с `НАЧНИТЕ_ЗДЕСЬ.html` или `ИНСТРУКЦИЯ_DOCKER.txt`: там пошаговый запуск для новичка.

| Файл | Действие |
| --- | --- |
| 01_start.bat | Обычная версия: http://localhost:8765, логин finguard, пароль в .env |
| 02_develop.bat | Разработка: http://localhost:5173, автоматическое обновление |
| 03_stop.bat | Остановка обоих режимов без удаления данных |
| 04_logs.bat | Последние сообщения сервисов |
| 05_test.bat | 89 тестов в Linux-контейнере |

Docker Desktop должен быть запущен. Достаточно Windows PowerShell; команды в Ubuntu не нужны.
Первый запуск создаёт .env со случайным паролем, если файл отсутствует. В архив пароль не включён.

Production: один non-root Python-контейнер с собранным React. Dev: Vite + Uvicorn reload с подключёнными исходниками; базы в отдельных именованных томах. Часовой пояс расчётов Europe/Moscow.

Все порты доступны только с локального компьютера. Для добавления зависимостей пересобирайте dev-образы. Python/Node устанавливаются внутри Docker. Финансовое ядро взято из FinGuard 6.2; банковских подключений и переводов нет.

Результаты реальной проверки: `DOCKER_VALIDATION.md` и `validation/`.
Архитектура и API: `docs/ARCHITECTURE.md`. Общая демонстрация: `docs/DEMO.md`.
Не запускайте несколько копий с одинаковыми Compose-именами как независимые установки.
